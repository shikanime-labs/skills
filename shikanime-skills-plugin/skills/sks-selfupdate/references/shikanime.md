# Shikanime org conventions

## Catalog

Repo `shikanime-labs/skills`; a full pass enumerates every catalog skill in
families (plus `nixpkgs`) from the `skills/` tree.

## Commit trailer

Commits carry the Automata co-author trailer; `sks-commit` holds the exact
trailer text and mechanics.

## Resync tap

Default tap for resync: `shikanime-labs/skills`.

- Working doctrine: long-term solutions over short-term fixes — fix the root
  cause, never land a tactical patch that accrues debt. No hard SLA
  constraints: correctness and durability outrank turnaround time; take the
  time to do it properly.
