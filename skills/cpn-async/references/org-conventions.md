# cpn-async — conventions d'org (cloud-pi-native)

À lire quand vous travaillez dans un dépôt de l'org cloud-pi-native.

- Dépôt par défaut : `cloud-pi-native/console` ; PR ouvertes avec
  `--head cloud-pi-native:<branch>` (origin-only : push vers l'`origin` du
  dépôt org).
- Trailer d'attribution d'agent (toujours, consigne opérateur) :
  `Co-authored-by: Automata <automata@shikanime.studio>`.
