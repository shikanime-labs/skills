# cpn-commit — org conventions (cloud-pi-native)

À lire quand vous committez dans un dépôt de l'org cloud-pi-native
(défaut : `cloud-pi-native/console`).

- Attribution agent TOUJOURS (consigne opérateur), en second bloc `-m` :
  `Co-authored-by: Automata <automata@shikanime.studio>`.
- Commits en anglais, même pour les changements doc-only ; scope et règles de
  review inchangés.
- Le dépôt est jj-backed : ne jamais `git commit`, passer par `jj describe` /
  `jj new`.
