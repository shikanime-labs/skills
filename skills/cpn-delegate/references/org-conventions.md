# cpn-delegate — conventions d'org (cloud-pi-native)

À lire quand vous isolez une unité dans un dépôt de l'org cloud-pi-native.

- Checkout par défaut : `~/Source/Repos/github.com/cloud-pi-native/console` ;
  le workspace frère devient `../console.<unite>`.
- Reviewer demandé à l'ouverture de PR : `yorha-operator` (compte Automata),
  sous réserve d'accès — voir `cpn-pr`.
