# cpn-discussion-triage — conventions d'org (cloud-pi-native)

À lire quand vous triez une Discussion dans un dépôt de l'org cloud-pi-native.

- Dépôt par défaut : `R=cloud-pi-native/console` ; exemples GraphQL :
  `repository(owner: "cloud-pi-native", name: "console")`.
- Langue des artefacts : **français**.
- Catégories (cloud-pi-native) : RFC/design → `Ideas` ; décision/discussion →
  `General` ; question → `Q&A`.
