# cpn-discussion — conventions d'org (cloud-pi-native)

À lire quand vous ouvrez/modifiez une Discussion dans un dépôt de l'org
cloud-pi-native.

- Dépôt cible : `cloud-pi-native/console` (Issues désactivées, Discussions
  actives) ; exemples GraphQL : `repository(owner: "cloud-pi-native",
  name: "console")`.
- Langue des artefacts (discussions, issues, PR) : **français**.
- Liens : URL complète ou `owner/repo#N` pour les refs cross-repo ; `#N` nu
  ne lie que dans console.
- Catégories : `General` (défaut pour une ouverture), `Ideas`.
- Une discussion est une **ouverture** (contexte + questions ouvertes), jamais
  « Décision attendue » / « Définition du fini » (périmètre `cpn-issue`).
