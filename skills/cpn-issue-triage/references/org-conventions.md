# cpn-issue-triage — conventions d'org (cloud-pi-native)

À lire quand vous triez une issue dans un dépôt de l'org cloud-pi-native.

- Dépôt par défaut : `R=cloud-pi-native/console`.
- Assignee de secours : `yorha-operator` (compte Automata) — seulement s'il
  figure dans la liste des assignees du dépôt.
- Autres dépôts de l'org vers lesquels transférer : `cloud-pi-native/*`
  (et, le cas échéant, `shikanime-labs/*`).
- Langue des artefacts : **français**.
