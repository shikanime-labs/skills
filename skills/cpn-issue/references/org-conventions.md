# cpn-issue — conventions d'org (cloud-pi-native)

À lire quand vous ouvrez une issue dans un dépôt de l'org cloud-pi-native.

- Dépôt cible / tracker : `cloud-pi-native/console` — toutes les requêtes et
  liaisons d'issues se font contre ce dépôt.
- Titres par template : bug → `🐛 [BUG] - <résumé>`, feature →
  `💡 [REQUEST] - <résumé>` ; labels seedés `bug` / `enhancement`. Templates
  [Templates complets en français](issue-templates.md).
- Langue des artefacts : **français** ; corps = énoncé du problème + ledger
  « Définition du fini » (`- [ ]`) + section Références.
- PRs souvent mal liées aux issues dans console : vérifier que l'issue liée
  décrit réellement le changement.
