# cpn-pr-triage — conventions d'org (cloud-pi-native)

À lire quand vous triez une PR dans un dépôt de l'org cloud-pi-native.

- Dépôt par défaut : `cloud-pi-native/console` (`gh project list --owner
  cloud-pi-native`).
- Reviewer de secours : `yorha-operator` (compte Automata) — sauf s'il est
  l'auteur de la PR (rejet GitHub 422).
- Langue des artefacts : **français**.
