# cloud-pi-native discussion specifics

Load when working in the cloud-pi-native/console repository.

## Org identity

- Target repo: `cloud-pi-native/console` — **Issues disabled, Discussions
  active** (the inverse of the shikanime layout); GraphQL examples use
  `repository(owner: "cloud-pi-native", name: "console")`.
- Artifact language: **français** — discussion bodies, sections, and comments
  follow the French house structure (`## Contexte`, open-question sections,
  `## PR liée` with a `#NNNN` link, not a raw URL).
- Categories: `General` (défaut pour une ouverture), `Ideas`.
- Links: full URL or `owner/repo#N` for cross-repo refs; bare `#N` links only
  within console.
- A discussion is an **ouverture** (contexte + questions ouvertes), never
  « Décision attendue » / « Définition du fini » (issue scope); lifecycle
  discussion → issue → issue comments → PR.
