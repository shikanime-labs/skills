# Org reference: shikanime

Consumed by `skills/issue/SKILL.md` to select shikanime-family behaviour.

## Target repos

- `shikanime-labs/*`
- `shikanime-studio/*`

The concrete repo is the one named in the task (e.g. `shikanime-labs/machines`).

## Behaviour

- **language**: en — write issue bodies and comments in English.
- **commit convention**: plain — plain-English imperative title, no conventional-commit prefix.
- **co-author trailer**: append `Co-Authored-By: Automata <automata@shikanime.studio>` to commits that land the resulting PR.
- **title prefix**: none.
- **label defaults**: `bug` for defects, `enhancement` for features.
