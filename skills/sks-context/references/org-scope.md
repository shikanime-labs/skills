# Shikanime Org Conventions

- Scope: work runs against `shikanime-labs/*` / `shikanime-studio/*`
  repos only; outside both, confirm the target repo with the user
  first.
- Org identity and repo layout: `sks-context`
  `references/shikanime.md`.
- Artifact language: titles, bodies, and close comments are written in
  English; keep repo values (labels, milestones, field options) exactly
  as stored.
- Working doctrine: long-term solutions over short-term fixes — fix
  the root cause, never land a tactical patch that accrues debt. No
  hard SLA constraints: correctness and durability outrank turnaround
  time; take the time to do it properly.
