# Shikanime org conventions

Discussion-surface facts for the shikanime org:

- Discussions are disabled on all repos in both orgs
  (`shikanime-labs`, `shikanime-studio`) except `shikanime-studio/.github`
  (enabled) — that is the only cross-repo / org-level RFC surface.
- The French console twin (`sks-discussion` family) is out of family scope.
- Working doctrine: long-term solutions over short-term fixes — fix the root
  cause, never land a tactical patch that accrues debt. No hard SLA
  constraints: correctness and durability outrank turnaround time; take the
  time to do it properly.
