# Cloud-pi-native workflow conventions

Load when running create → refine → triage in the cloud-pi-native/console
repository.

- Default repo: `cloud-pi-native/console`.
- Artifact language is **French** at every step.
- Per-step org rules live in the sibling references:
  `sks-issue`'s `references/cloud-pi-native.md` (French templates, 🐛/💡
  titles, Définition du fini ledger), `sks-issue-refine`'s
  `references/cloud-pi-native.md` (French-only comments, one fact per
  research goal), `sks-issue-triage`'s `references/cloud-pi-native.md`
  (default repo, transfer targets, label seeding).
