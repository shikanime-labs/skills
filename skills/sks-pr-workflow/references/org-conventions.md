# Org conventions (shikanime)

## Repos and checkouts

Org repos live under `shikanime-labs/*` / `shikanime-studio/*`. Local
checkouts sit at `~/Source/Repos/github.com/<org>/<repo>`; jj workspaces for
a repo are siblings of it.

## PR push/open

Push to `origin` (the org repo) and open with `--head <org>:<branch>`, base
`main`.
