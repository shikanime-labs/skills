# Org conventions (shikanime)

## Catalog

Repo `shikanime-labs/skills`; a full pass enumerates every catalog skill in
families (plus `nixpkgs`) from the `skills/` tree.

## Commit trailer

Commits carry the Automata co-author trailer; `sks-commit` holds the exact
trailer text and mechanics.

## Resync tap

Default tap for resync: `shikanime-labs/skills`.
